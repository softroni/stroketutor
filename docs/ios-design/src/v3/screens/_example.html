Developer notes

Purpose

One question, one answer: what do I draw next? The hero answers it; the path shows where it leads.

Layout

  • Scrolling body; 36 pt title with a gold chip for the sketchbook count on the right (a fact, not a score).
  • .card--hero: eyebrow 12/800, title 24/800, meta 15/600 at 78 % white; a 96 pt white .thumb; a white primary button with green text.
  • .path: 84 pt nodes, rows alternate --x ±40 pt, labels on the outer side.

What changed in v3

  • White page, hero banner instead of a bordered card, nodes instead of rows, tactile buttons. Duolingo for the banner and node pattern, §30 for what is deliberately missing.

SwiftUI mapping

ScrollView { VStack(spacing: 12) { title; HeroCard(next); PathView(nodes) } }
LessonNode(state: .done | .current | .locked, drawing: tutorial)
